    Cliente¶

    Banxico ¶

    Cliente del SIE de Banco de México.

    Parameters:

    Name Type Description Default
    token (str, opcional)

    Token de consulta. Lo normal es no pasarlo y dejar que se resuelva desde el entorno; ver :func:siebanxico.obtener_token.

    		 None
    timeout float

    Segundos de espera por petición.

    		 30
    reintentos int

    Reintentos ante fallas de red o errores 5xx (con espera creciente).

    		 3
    cache bool

    Guarda en memoria las respuestas para no gastar consultas repitiendo la misma petición. Banxico recomienda expresamente cachear.

    		 True
    espera_maxima float

    Si se supera el límite de consultas y el desbloqueo ocurre en menos de estos segundos, se espera y se reintenta; si no, se lanza :class:~siebanxico.LimiteExcedido.

    		 60
    sesion (Session, opcional)

    Sesión propia (proxies, certificados corporativos, pruebas).

    		 None

    Examples:

    >>> import siebanxico as sie
>>> bmx = sie.Banxico()
>>> bmx.descargar(["inpc", "fix"], inicio="2015-01-01")

    descargar ¶

    descargar(series=None, inicio=None, fin=None, *, tema=None, incremento=None)

    Descarga una o varias series y las devuelve alineadas por fecha.

    Hay tres formas de decir qué se quiere: por clave del SIE, por alias del catálogo o un tema completo.

    Parameters:

    Name Type Description Default
    series str, lista o dict

    Identificadores del SIE ("SF43718"), alias del catálogo ("fix") o un diccionario {clave: nombre_de_columna}. No hay límite de 20 series: la consulta se parte en lotes automáticamente.

    		 None
    tema (str, opcional)

    En lugar de series, todas las del catálogo de un tema ("tasas", "tipo_de_cambio"…); ver :func:siebanxico.catalogo.

    		 None
    inicio (fecha, opcional)

    Cualquier cosa que entienda pandas.Timestamp. Si se omiten ambas se descarga la historia completa; si falta fin se usa hoy.

    		 None
    fin (fecha, opcional)

    Cualquier cosa que entienda pandas.Timestamp. Si se omiten ambas se descarga la historia completa; si falta fin se usa hoy.

    		 None
    incremento ('mensual', 'anual', 'acumulado')

    Pide a Banxico la variación porcentual ya calculada en lugar del nivel: respecto a la observación anterior, al mismo periodo del año anterior, o al cierre del año anterior.

    		 "mensual"

    Returns:

    Type Description
    DataFrame

    DatetimeIndex llamado fecha, una columna por serie y valores float (NaN donde el SIE reporta N/E). Las fechas sin ningún dato se descartan. Los títulos oficiales quedan en df.attrs["series"].

    Raises:

    Type Description
    SerieNoEncontrada

    Si alguna clave no existe en el SIE.
    SinDatos

    Si ninguna serie tiene observaciones en el periodo.

    panel ¶

    panel(series=None, inicio=None, fin=None, *, tema=None, como=None)

    Panel mensual listo para analizar, aunque las series tengan frecuencias distintas.

    Descarga las series y lleva a frecuencia mensual las diarias, semanales y quincenales, cada una con la regla que le corresponde según el catálogo: último dato para precios y saldos, promedio para tasas, suma para flujos. Evita tener que descargar por grupos y agregar a mano.

    Parameters:

    Name Type Description Default
    series Series | None

    Igual que en :meth:descargar.

    		 None
    inicio Series | None

    Igual que en :meth:descargar.

    		 None
    fin Series | None

    Igual que en :meth:descargar.

    		 None
    tema Series | None

    Igual que en :meth:descargar.

    		 None
    como (dict, opcional)

    {columna: regla} para cambiar la regla de alguna serie o fijar la de una clave que no está en el catálogo (por omisión, "ultimo"). Reglas: "ultimo", "promedio", "suma", "primero".

    		 None

    Returns:

    Type Description
    DataFrame

    Indexado al primer día de cada mes. La regla aplicada a cada columna queda en df.attrs["agregacion"].

    Examples:

    >>> import siebanxico as sie
>>> sie.panel(["inpc", "fix", "tasa_objetivo"], "2015-01-01")

    diagnostico ¶

    Conocer los datos antes de transformarlos, y verificar después.

    diagnostico ¶

    diagnostico(datos)

    Resumen mínimo por serie: cobertura, frecuencia, faltantes y rango.

    La columna razon_max_min orienta sobre el logaritmo: si una serie positiva se multiplicó varias veces, su varianza casi seguro crece con el nivel.

    faltantes cuenta los huecos entre la primera y la última observación de cada columna, así que diagnostica por separado las series de frecuencias distintas: al juntarlas en una tabla, los días sin dato mensual contarían como faltantes.

    prueba_adf ¶

    prueba_adf(datos, alfa=0.05)

    Prueba Dickey–Fuller Aumentada para una o varias series.

    Acepta un diccionario {nombre: serie}, ideal para comparar la misma variable bajo distintas transformaciones. H0: la serie tiene raíz unitaria; se rechaza (estacionaria = True) cuando p_valor < alfa.

    Requiere statsmodels (pip install statsmodels).

    a_mensual ¶

    a_mensual(datos, como='ultimo')

    Lleva una serie de alta frecuencia a frecuencia mensual.

    Parameters:

    Name Type Description Default
    datos Series o DataFrame

    Serie diaria o semanal.

    		 required
    como ('ultimo', 'promedio', 'suma', 'primero')

    Regla de agregación. La elección no es neutral: "ultimo" para precios y saldos (tipo de cambio, reservas), "promedio" para tasas de interés, "suma" para flujos. Promediar un precio reduce artificialmente su volatilidad. Con un DataFrame puede darse un diccionario {columna: regla}.

    		 "ultimo"

    Returns:

    Type Description

    Indexado al primer día de cada mes, igual que las series mensuales del SIE, para que se puedan unir sin desfases.

    Tendencia y pronósticos¶

    impulso ¶

    impulso(indice, meses=3, *, ajustar=True)

    Ritmo reciente de la inflación: promedio móvil contra el previo, anualizado.

    Compara el promedio del índice en los últimos meses con el de los meses anteriores y anualiza el resultado (el «3m/3m anualizado» de los reportes de bancos centrales). Detecta los cambios de tendencia varios meses antes que la variación anual, que arrastra lo ocurrido hace un año.

    Parameters:

    Name Type Description Default
    indice Series

    Índice de precios mensual.

    		 required
    meses int

    Tamaño de la ventana (3 o 6 son los habituales).

    		 3
    ajustar bool

    Desestacionaliza antes con :func:siebanxico.desestacionalizar (requiere statsmodels). Sin ajuste, el resultado refleja sobre todo el calendario.

    		 True

    Returns:

    Type Description
    Series

    En % anualizado.

    persistencia ¶

    persistencia(serie, rezagos=12, ventana=None)

    Persistencia de la inflación: suma de los coeficientes de un AR(p).

    Cerca de 1, los choques tardan mucho en disiparse (la inflación se comporta casi como una caminata aleatoria); cerca de 0, se revierten pronto.

    Parameters:

    Name Type Description Default
    serie Series

    Inflación mensual (idealmente desestacionalizada) u otra serie estacionaria.

    		 required
    rezagos int

    Orden p del autorregresivo, estimado por mínimos cuadrados.

    		 12
    ventana (int, opcional)

    Si se indica, estima en ventanas móviles de ese tamaño y devuelve un Series para ver cómo cambia en el tiempo; si no, un solo número.

    		 None

    pronosticar_inflacion ¶

    pronosticar_inflacion(indice, horizonte=12, *, metodo='sarima', nivel=0.9, orden=(0, 1, 1), orden_estacional=(0, 1, 1, 12), simulaciones=2000, semilla=0)

    Pronostica la inflación a partir del índice de precios.

    Parameters:

    Name Type Description Default
    indice Series

    Índice de precios mensual (INPC, subyacente…), al menos 5 años.

    		 required
    horizonte int

    Meses a pronosticar.

    		 12
    metodo ('sarima', 'ingenuo')
    • "sarima": SARIMA sobre el logaritmo del índice. El valor por omisión, (0,1,1)(0,1,1)₁₂, es el «modelo de aerolíneas», la referencia habitual para series mensuales con estacionalidad.
    • "ingenuo": la inflación anual se mantiene en su último valor. Es sorprendentemente difícil de superar a 12 meses; todo modelo debería compararse contra él.
    		 "sarima"
    nivel float

    Cobertura del intervalo (0.90 → de 5 % a 95 %). Solo con "sarima".

    		 0.9
    orden tuple

    Especificación del SARIMA.

    		 (0, 1, 1)
    orden_estacional tuple

    Especificación del SARIMA.

    		 (0, 1, 1)
    simulaciones int

    Trayectorias simuladas para construir el intervalo de la inflación anual, que depende de varios meses pronosticados a la vez.

    		 2000
    semilla (int, opcional)

    Fija las simulaciones para que el resultado sea reproducible.

    		 0

    Returns:

    Type Description
    DataFrame

    Una fila por mes futuro: indice, mensual, anual y, con SARIMA, anual_inf y anual_sup. Todo en % salvo el índice.
    Notes

    El intervalo refleja solo la incertidumbre de los choques futuros bajo el modelo; no incluye la de los parámetros ni la de haber elegido mal el modelo, así que es más estrecho que la incertidumbre real.

    evaluar_pronosticos ¶

    evaluar_pronosticos(indice, horizontes=(1, 3, 6, 12), *, desde=None, paso=3, metodos=METODOS, orden=(0, 1, 1), orden_estacional=(0, 1, 1, 12))

    Compara los métodos con pronósticos fuera de muestra de origen móvil.

    Para cada fecha de origen se estima el modelo solo con los datos disponibles hasta entonces, se pronostica la inflación anual y se compara con lo que realmente ocurrió.

    Parameters:

    Name Type Description Default
    horizontes tuple de int

    Meses hacia adelante a evaluar.

    		 (1, 3, 6, 12)
    desde (fecha, opcional)

    Primer origen. Por omisión, el último tercio de la muestra.

    		 None
    paso int

    Meses entre orígenes consecutivos. 1 es lo más preciso y lo más lento (cada origen reestima el SARIMA).

    		 3

    Returns:

    Type Description
    DataFrame

    Raíz del error cuadrático medio, en puntos porcentuales de inflación anual, por horizonte (filas) y método (columnas), más n pronósticos evaluados. Los errores individuales quedan en .attrs["errores"].

    Rendimientos e inflación implícita¶

    rendimiento_bono ¶

    rendimiento_bono(precio_limpio, cupon, plazo_dias, valor_nominal=100, dias_cupon=182)

    Rendimiento a vencimiento (% anual) a partir del precio limpio.

    Inversa de :func:precio_bono, resuelta por bisección. Para un Udibono, el precio debe estar en UDIS (precio en pesos entre el valor de la UDI) y el resultado es un rendimiento real.

    Examples:

    >>> round(float(rendimiento_bono(100, 8, 3640)), 4)   # a la par rinde su cupón

    precio_bono ¶

    precio_bono(rendimiento, cupon, plazo_dias, valor_nominal=100, dias_cupon=182)

    Precio limpio de un bono a tasa fija con la convención mexicana.

    Parameters:

    Name Type Description Default
    rendimiento número o Series

    Rendimiento a vencimiento, en % anual.

    		 required
    cupon número o Series

    Tasa cupón, en % anual.

    		 required
    plazo_dias número o Series

    Días por vencer.

    		 required
    valor_nominal float

    100 pesos en los Bonos M; 100 UDIS en los Udibonos.

    		 100
    dias_cupon int

    Días entre cupones (182).

    		 182
    Notes

    Con R = rendimiento × 182/360, cupón C = VN × cupón × 182/360, K cupones por cobrar y d días transcurridos del cupón vigente:

    precio sucio = [C + C·(1/R − 1/(R(1+R)^(K−1))) + VN/(1+R)^(K−1)] / (1+R)^(1−d/182)

    y el precio limpio descuenta los intereses devengados C·d/182.

    inflacion_implicita ¶

    inflacion_implicita(nominal, real)

    Inflación implícita (breakeven): (1 + i) / (1 + r) − 1, en %.

    Es la inflación promedio que iguala el rendimiento de un bono nominal con el de uno indexado a la inflación del mismo plazo.

    Parameters:

    Name Type Description Default
    nominal número o Series

    Rendimiento nominal (Bono M, Cetes), en % anual.

    		 required
    real número o Series

    Rendimiento real (Udibono), en % anual.

    		 required
    Notes

    No es una expectativa pura. Incluye una prima por riesgo inflacionario (la sube) y una prima de liquidez de los Udibonos (la baja). Banxico la llama «compensación por inflación y riesgo inflacionario». Compárala con las expectativas de la encuesta ("expectativa_inflacion_12m") antes de interpretarla.

    Examples:

    >>> round(inflacion_implicita(9.5, 5.0), 4)
4.2857

    prueba_adf(datos, alfa=0.05)
